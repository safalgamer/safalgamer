# ocean-portfolio

**Personal portfolio website with an ocean theme.**

A clean, responsive static portfolio site built with vanilla HTML, CSS, and JavaScript.

## features

- Ocean-themed visual design
- Responsive layout (desktop + mobile)
- Project showcase section
- Contact information
- No framework dependencies — pure HTML/CSS/JS

## usage

Open `index.html` in any browser, or serve locally:

```bash
npx serve .
```

## tech stack

HTML5, CSS3, JavaScript (vanilla)
